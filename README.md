# ИАС обнаружения мошеннических транзакций
Прототип информационно-аналитической системы выявления подозрительных платежных операций с использованием алгоритмов машинного обучения. Репозиторий содержит код прототипа, подготовленного в рамках работы над ВКР.

## Описание программы
Программа предоставляет возможности:
- обучения модели на тренировочных данных и сохранение результатов обучения
- проверка перформанса обученной модели
- графический клиент для демонстрации работы ИАС
- дамп артефактов, результатов тестирования модели

## Инструкция запуска прототипа
### 1.Клонирование репозитория
Скопируйте URL репозитория и перейдите в папку, в которую хотите клонировать содержимое репозитория.
Введите:
```bash
git clone <URL репозитория>
```
Перейдите в папку репозитория.
Откройте интферфейс командной строки в этой папке.
### 2.Создание виртуального окружения и установка зависимостей
Для Windows:
```bash
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```
Для Linux/macOS:
```bash
python3 -m venv .venv
source .venv\bin\activate
python3 -m pip install --upgrade pip
pip install -r requirements.txt
```
### 3.Подготовка датасета
Скачайте архив датасета по ссылке https://www.kaggle.com/competitions/ieee-fraud-detection/data и распакуйте его в папку data.
